Contrato de um Domain Event
public abstract class DomainEvent { public Guid EventId { get; } = Guid.NewGuid(); // idempotência public DateTime OcorridoEm { get; } = DateTime.UtcNow; public string TenantId { get protected set; } = ""; public abstract string EventType { get; } // ex: "VendaFaturada" } // Exemplo de evento concreto public class VendaFaturadaEvent : DomainEvent { public override string EventType => "VendaFaturada"; public Guid VendaId { get init; } public Guid EmpresaId { get init; } public decimal TotalNota { get init; } public ModeloFiscal ModeloFiscal { get init; } }
Por que Outbox Pattern é obrigatório
Sem Outbox: se a API responde 200 OK mas o broker de eventos falha logo depois, o evento se perde. O banco ficou atualizado mas o módulo consumidor nunca soube. Inconsistência garantida a escala.
Com Outbox: evento é persistido na mesma transação ACID do comando. Mesmo que a API caia imediatamente após o SaveChanges, o evento está no banco. Worker faz retry até entregar.
Fluxo completo
Handler executa
→
Entidade muda estado
→
OutboxMessage.Criar()
→
SaveChanges (atômico)
→
Worker Quartz (poll 5s)
→
Evento entregue ao handler

Worker — lógica de processamento
// Quartz.NET job — executa a cada 5 segundos // Lê OutboxMessages não processados (processado_em IS NULL) // Ordena por criado_em ASC — garante entrega ordenada por tenant // Tenta entregar ao handler do módulo consumidor // Sucesso: seta processado_em = UtcNow // Falha: incrementa tentativas, registra erro, aplica backoff // Após 10 tentativas: move para dead_letter_queue para análise manual SELECT * FROM plataforma.outbox_messages WHERE processado_em IS NULL AND tentativas < 10 AND (prox_tentativa_em IS NULL OR prox_tentativa_em <= NOW()) ORDER BY tenant_id, criado_em ASC LIMIT 100 FOR UPDATE SKIP LOCKED; -- safe para múltiplas instâncias da API

Extensões PostgreSQL ativas
uuid-osspGeração UUID v4 no banco — fallback quando app não gera. gen_random_uuid() como default em PKs.
pg_trgmBusca full-text trigram. Índices GIN em descrição de produto, nome de pessoa. similarity() para busca aproximada.
unaccentNormalização de texto para busca sem acento. "Joao" encontra "João". Configurado no collation.
pgcryptoCriptografia de colunas PII: CPF, CNPJ, e-mail, telefone. pgp_sym_encrypt/decrypt com chave no Vault.
pgvectorPlanejado para Fase IA/ML. Embeddings de produtos para busca semântica e recomendações.
