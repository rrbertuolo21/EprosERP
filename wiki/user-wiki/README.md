# Epros — Wiki do Usuário

## O que é o Epros
O Epros é um **ERP na nuvem (SaaS) multiempresa**: um sistema de gestão que a sua empresa acessa pelo navegador,
sem instalar nada, pagando uma assinatura. Ele reúne num só lugar cadastros, vendas, compras, estoque, financeiro,
fiscal e outras áreas do dia a dia. "Multiempresa" quer dizer que, com um único acesso, você pode operar mais de uma
empresa (matriz e filiais, ou negócios diferentes), cada uma com seus dados separados e protegidos. Cada cliente
contrata um **plano**, que define quais módulos e limites estão liberados.

Esta wiki explica, em linguagem de negócio, **o que cada módulo faz e como usar**. Para o detalhe técnico, veja a
[dev-wiki](../dev-wiki/README.md).
