Trilhas de
Aprendizado

Uma trilha por função, baseada nos componentes reais do Epros. Exercícios práticos no contexto do projeto — não tutoriais genéricos.

4 trilhas — clique para expandir
Cada trilha tem 8 semanas. Pode ser seguida em paralelo com o trabalho — 2–3 horas por semana. Os exercícios usam o código real do repositório PlataformaSaaS/.
Como usar: abra o Cursor com os agentes configurados. A maioria dos exercícios começa com "Cole no Cursor Chat" e termina com "faça o PR". O aprendizado acontece no contexto real do projeto.

Treinamento › Onboarding — Primeiro Dia
Primeiro Dia no Time
O que um novo membro precisa fazer nos primeiros dias para estar operacional. Sequência obrigatória — não pular etapas.
Checklist de setup — Dia 1
1
Ler os 4 documentos base
Antes de qualquer setup técnico, leia na ordem: epros-diagnostico.html → epros-estrategico.html → epros-modulos.html → epros-tecnico.html. Você vai entender o que foi, o que é e o que será.
Leitura: ~2 horas
2
Clonar os repositórios
PlataformaSaaS/ (backend), epros_erp_front-main/ (frontend). Solicitar acesso ao Tech Lead no primeiro dia.
git clone git@github.com:epros/PlataformaSaaS.git
3
Subir o ambiente local
docker compose up -d na raiz do PlataformaSaaS/. Verificar que todos os 9 serviços sobem com healthcheck verde. Ver epros-tecnico.html → Infra Local para credenciais.
docker compose up -d && docker compose ps
4
Configurar o Cursor
Instalar o Cursor. Settings → Rules → criar perfis de agente baseados na sua função (ver epros-agentes-prompts.md). Verificar que o .cursorrules está sendo reconhecido.
Cursor → Settings → Rules → New Rule
5
Rodar os testes locais
dotnet test na raiz do projeto. Os 8 testes obrigatórios precisam passar. Se algum falhar, chamar o Tech Lead antes de qualquer commit.
cd PlataformaSaaS && dotnet test
6
Primeiro PR — tarefa de onboarding
Tech Lead vai ter uma task de onboarding preparada. Pequena, bem definida, com ACs claros. Usar o fluxo completo: Code Review Agent → PR → aguardar aprovação.
Tech Lead define a task de onboarding
7
Reunião com o Guardião de Domínio
Marcar 1h com o Dev de 10 anos para entender o contexto de negócio do módulo em que vai trabalhar. Ele conhece as regras fiscais, os fluxos críticos e por que certas decisões foram tomadas.
30–60 minutos de conversa
8
Começar a trilha de função
Abrir o epros-treinamento.html e iniciar a semana 1 da trilha correspondente à função. As trilhas são para rodar em paralelo com o trabalho — não bloqueia.
epros-treinamento.html → sua função
