Missão e princípio fundador
Missão

ERP de nível SAP, acessível para qualquer empresa

Construir um ERP completo, modular e cloud-agnostic que dá a PMEs e grandes corporações o mesmo poder de gestão que SAP S/4HANA e Oracle ERP Cloud — sem licença proibitiva, sem lock-in de cloud e com compliance nativo para operar em qualquer mercado do mundo.

Princípio fundador

Portabilidade total como requisito não-funcional

Qualquer componente que exija contrato com AWS, Azure ou GCP é substituído por equivalente open source com paridade funcional. O sistema roda identicamente em VPS de €20/mês, data center próprio ou qualquer cloud — sem alterar uma linha de código. Isso não é feature. É princípio arquitetural inegociável.

Por que isso importa para o negócio
Mercado global real

Zero lock-in geográfico

Clientes em países com restrições a clouds americanas (Brasil Gov, China, Rússia, Índia) conseguem usar. On-premise vira diferencial comercial contra SAP e Oracle — que exigem cloud própria ou parceiro certificado caro.

Previsibilidade de custos

Custo cresce linearmente

Com 10.000 tenants, AWS/Azure sobem preços 30–40% ao ano. Com infra própria, custo cresce linearmente com volume — previsível e controlável. Margem protegida a escala.

Soberania de dados

O cliente escolhe onde os dados vivem

LGPD, GDPR, PDPA e PIPL exigem dados em território nacional. Com self-hosted ou cloud local, o cliente tem conformidade automática — sem depender de configurações do provedor de cloud.

Modelo comercial — dimensões de billing

Por módulo ativo

Fee mensal por módulo habilitado. Desabilitar preserva dados históricos e para de cobrar imediatamente.

Por usuário nomeado

Preço por assento (concurrent ou named). Combinável com fee de módulo.

Por volume transacional

Híbrido com teto

Proposta de valor por persona
Para o CTO / Tech Lead

Arquitetura que não envergonha

Monólito Modular com Hexagonal por bounded context. Schema próprio por módulo no PostgreSQL, interfaces públicas explícitas, Domain Events com Outbox Pattern. Sem big ball of mud. Preparado para extração em microserviços quando necessário — sem reescrever nada. Stack 100% open source, MIT/Apache.

Para o CEO / CFO

ERP completo sem surpresas de custo

Zero licença de banco, cloud ou observabilidade. Compliance nativo com 12 regulações globais — sem add-ons extras. DMS, ESG e GRC de primeira classe. On-premise disponível para regulados. Custo cresce linearmente com volume, nunca de surpresa.

ICP & mercado-alvo

Ideal Customer Profile por plano. Cada segmento tem necessidades diferentes — o Epros atende do Micro ao Enterprise sem forçar módulos desnecessários.

ICP por plano

Micro Micro e pequenas empresas

  • Comércio varejista, e-commerce, prestadores de serviço
  • 1–15 usuários simultâneos
  • Faturamento: até R$ 4,8M/ano (MEI a pequeno porte)
  • Necessidade: NF-e, fluxo de caixa, controle de estoque
  • Pain point atual: sistemas desconectados, planilhas, sem fiscal
  • Churn risk: preço. Retenção: integração fiscal nativa.

Essencial PMEs com manufatura

  • Indústria leve, distribuidoras, atacadistas
  • 10–100 usuários simultâneos
  • Faturamento: R$ 5M–50M/ano
  • Necessidade: produção (BOM/MRP), qualidade, RH/folha
  • Pain point atual: ERP legado caro, sem integração entre módulos
  • Churn risk: funcionalidade incompleta. Retenção: módulos integrados.

Avançado Médias empresas com compliance

  • Construção civil, utilities, saúde, agro
  • 50–500 usuários simultâneos
  • Faturamento: R$ 50M–500M/ano
  • Necessidade: manutenção (EAM), projetos (PPM), GRC/SOX
  • Pain point atual: sistemas separados, audit trail inexistente
  • Churn risk: compliance. Retenção: GRC + audit trail imutável.

Enterprise Grupos e regulados

  • Grupos empresariais, concessionárias, montadoras, bancos, regulados BACEN/ANVISA
  • 500+ usuários, multi-empresa, multi-moeda
  • Faturamento: R$ 500M+/ano
  • Necessidade: DMS, ESG (CSRD obrigatório EU), on-premise, BYOK
  • Pain point atual: SAP/Oracle inacessível ou engessado
  • Churn risk: lock-in. Retenção: on-premise + compliance global.
Segmentos verticais prioritários

Concessionárias automotivas

DMS nativo — único ERP nacional com gestão de concessionárias de primeira classe. Vendas, serviços, peças, CRM, garantias, finanças integrados.

Indústria de manufatura

BOM multi-nível, MRP/IBP (S&OP, what-if), MES, QUA com NCR/CAPA, rastreabilidade de lote e recall.

Empresas com ESG obrigatório

CSRD (EU) obriga empresas com operação europeia a reportar ESG. Epros tem módulo ESG nativo com GRI, CSRD, TCFD, SASB.

Regulados BACEN / ANVISA

On-premise com BYOK. Audit trail imutável. Compliance PCI DSS. Deploy no ambiente do cliente sem dados na cloud.

Comércio e distribuição

PDV nativo com NFC-e offline, WMS, TMS logístico com CO₂ por rota, CLM de compra e venda.

Projetos e construção

PPM completo: WBS, cronograma, EVM, orçamento, riscos, portfólio. Integração com FIN para reconhecimento de receita por percentual de conclusão.

Diferenciais competitivos

6 diferenciais que nenhum concorrente entrega de forma integrada. Cada um sozinho já seria um argumento de venda. Juntos, formam uma posição defensável.

01 — DMS Nativo

Gestão de Concessionárias integrada

Único ERP nacional com DMS de primeira classe — não um add-on. Vendas de veículos, configuração, financiamento, comissões, OS de serviço, peças, CRM, garantias, metas por rede, DRE por unidade. Integração real com módulos FIN, EST e MAN.

vs SAP: parcial via parceiro · vs Oracle: não tem · vs TOTVS: módulo separado
02 — Fiscal BR Nativo

Motor fiscal sem dependência de terceiros

NF-e (55), NFC-e (65), NFS-e, CT-e, SPED Fiscal, SPED Contábil, eSocial, REINF — tudo dentro do Epros. Contingência offline para PDV. Lib Hercules.NET.NFe.NFCe v2026 já em produção nos 20 clientes Epros.ERP.

vs SAP: add-on pago · vs Oracle: localização cara · vs TOTVS: tem, mas monolítico
03 — ESG & GRC nativos

Compliance como módulo de primeira classe

ESG: pegada de carbono Scope 1/2/3, GRI, CSRD (obrigatório para empresas na EU), TCFD, SASB. GRC: risk register, SOX, SoD, audit trail imutável, Whistleblower, gestão de políticas. Não são add-ons — são módulos integrados.

vs SAP: módulo separado caro · vs Oracle: parcial · vs TOTVS: não tem
04 — Cloud-Agnostic by design

3 níveis de deploy, 1 binário

Shared cluster (Micro/Essencial), dedicated cluster (Avançado/Enterprise) e on-premise / cloud própria — exatamente o mesmo binário, sem fork, sem código condicional. A diferença está inteiramente no Catalog + Connection Router.

vs SAP: cloud própria · vs Oracle: cloud only · vs TOTVS: on-premise sem SaaS
05 — Multi-surface

Web + Desktop offline + Mobile + PDV

4 surfaces com um backend. Desktop com SQLite offline-first e motor fiscal edge. Mobile com React Native para campo e aprovações. PDV com NFC-e contingência — funciona sem internet. Todas as surfaces consomem a mesma API REST.

vs todos: nenhum concorrente tem PDV offline nativo + Desktop + Mobile integrados
06 — Compliance 12 regulações

By design — não configurável depois

LGPD, GDPR, PCI DSS 4.0, CCPA, PDPA, PIPEDA, PDPL, DPDP, PIPL, Privacy Act/APP, SOC 2 Type II, ISO 27001. Controles técnicos implementados desde o primeiro commit — não como configuração posterior.

vs todos: concorrentes tratam compliance como configuração, não arquitetura

Plataforma multi-surface

4 surfaces com um único backend. O core de negócio vive 100% na API cloud. Cada surface é um adapter que consome essa API — e quando offline, consome um runtime local que sincroniza ao reconectar.
